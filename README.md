# Website Katalog Koperasi Unit Desa Tenera

Website katalog ini dikembangkan untuk **Koperasi Unit Desa (KUD) Tenera Mukti** sebagai sarana untuk menampilkan informasi mengenai produk, layanan, dan kegiatan koperasi. Website ini bertujuan untuk memberikan kemudahan akses bagi anggota koperasi dan masyarakat dalam mengetahui layanan yang tersedia.

## Fitur Utama
- **Katalog Produk & Layanan**: Menampilkan daftar produk dan layanan yang disediakan oleh KUD Tenera.
- **Manajemen Data Koperasi**: Memudahkan pengelolaan informasi terkait anggota, pinjaman, dan transaksi.
- **Responsif & User-Friendly**: Desain yang responsif sehingga dapat diakses dari berbagai perangkat.
- **Pencarian & Filter**: Memudahkan pengguna untuk menemukan informasi yang mereka butuhkan.

## Teknologi yang Digunakan
- **Framework**: CodeIgniter 3
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP (CodeIgniter 3)
- **Database**: MySQL
- **Integrasi API**: Google Maps API (jika diperlukan untuk lokasi koperasi)

## Cara Instalasi
1. Clone repositori ini:
   ```sh
   git clone https://github.com/username/repo.git
   ```
2. Masuk ke direktori proyek:
   ```sh
   cd repo
   ```
3. Konfigurasi file **application/config/config.php**, **application/config/database.php**, dan file lainnya sesuai kebutuhan.
4. Buat database dan impor file SQL yang tersedia.
5. Jalankan server lokal menggunakan XAMPP atau server PHP lainnya.
6. Akses website melalui `http://localhost/nama_project`
